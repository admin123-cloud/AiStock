ℹ️ 关于

StockPy - 大盘情绪监控系统

一个集成实时市场数据、技术分析、自动回测和情绪监控的A股量化交易平台。

核心功能

  • 📊 A股K线数据管理（多周期）
  • 📈 大盘情绪指标计算
  • ⏰ 定时数据更新任务
  • 🔧 技术指标分析框架
  • 🧪 回测系统架构
  • 🔔 WebSocket 实时推送

计划功能

  • 接入真实市场数据API（腾讯财经、东方财富）
  • 添加技术指标分析（MA、MACD、RSI等）
  • 实现告警机制（情绪突变提醒）
  • 支持自定义指标权重
  • 用户认证和权限管理
  • 数据导出（CSV、Excel）

技术栈

后端：FastAPI + SQLAlchemy + APScheduler

前端：HTML + CSS + JavaScript + ECharts

数据库：SQLite / MySQL
