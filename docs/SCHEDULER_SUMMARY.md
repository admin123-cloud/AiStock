# 定时任务调度器 - 实现总结

## 项目概述

已成功创建完整的定时任务调度器模块，用于执行周期性数据同步任务。

## 功能特性

### 1. 交易日历工具 (`src/scheduler/trading_calendar.py`)

提供完整的交易日历判断功能：

- **判断交易日**: `is_trading_day()` - 判断是否为交易日
- **判断交易时间**: `is_trading_time()` - 判断是否在交易时间内
- **判断市场开盘**: `is_market_open()` - 判断市场是否开盘
- **计算开盘时间**: `time_to_market_open()` - 计算距离开盘的时间
- **计算收盘时间**: `time_to_market_close()` - 计算距离收盘的时间
- **查找交易日**: `get_next_trading_day()` / `get_previous_trading_day()`

交易时间配置：
- 上午: 09:30 - 11:30
- 下午: 13:00 - 15:00
- 交易日: 周一至周五

### 2. 定时任务配置 (`src/scheduler/config.py`)

统一的配置管理，支持灵活的参数调整：

```python
SCHEDULER_CONFIG = {
    "enabled": True,  # 总开关

    "jobs": {
        "full_sync_kline": {
            "enabled": True,
            "cron_expression": "0 1 * * 6",  # 每周六凌晨1点
        },
        "realtime_quotes": {
            "enabled": True,
            "interval": 60,  # 每60秒
        }
    }
}
```

### 3. 定时任务定义 (`src/scheduler/jobs.py`)

实现了两个核心任务：

#### 全量K线同步任务
- **执行时间**: 每周六凌晨1点
- **同步周期**: 日线(1d)、周线(1w)、月线(1M)、季线(1Q)、年线(1Y)
- **数据复权**: 前复权 (forward)
- **处理方式**: 分批处理（默认50只/批），批次间延迟1秒
- **重试机制**: 使用TickFlowClient的内置重试（3次，指数退避）

#### 实时行情更新任务
- **执行时间**: 盘中每分钟
- **执行条件**: 仅在交易日和交易时间内执行
- **更新范围**: 自选股列表
- **实时性**: 60秒更新间隔

### 4. 调度器核心 (`src/scheduler/scheduler.py`)

异步任务调度器，支持：

- 单例模式
- 优雅启动/停止
- 信号处理（Ctrl+C）
- 并发任务管理
- 错误处理和日志记录

### 5. 命令行工具 (`src/scheduler/cli.py`)

提供完整的命令行接口：

```bash
python scheduler_run.py config      # 查看配置
python scheduler_run.py trading     # 查看交易日信息
python scheduler_run.py sync        # 手动执行全量同步
python scheduler_run.py quotes      # 手动执行行情更新
python scheduler_run.py start       # 启动调度器
```

## 配置说明

### 启用/禁用任务

编辑 `src/scheduler/config.py`:

```python
# 禁用整个调度器
SCHEDULER_CONFIG["enabled"] = False

# 禁用单个任务
SCHEDULER_CONFIG["jobs"]["full_sync_kline"]["enabled"] = False
```

### 调整执行时间

```python
# 修改全量同步时间（例如改为每周日2点）
"cron_expression": "0 2 * * 0"  # 每周日凌晨2点

# 修改实时行情更新间隔
"interval": 30  # 每30秒更新一次
```

### 调整同步参数

```python
"sync": {
    "kline": {
        "periods": ["1d", "1w"],  # 只同步日线和周线
        "count": 1000,             # 每次获取1000条
        "batch_size": 20,         # 每批20只股票
        "delay_between_batches": 2.0,  # 批次间延迟2秒
    }
}
```

## 技术特点

1. **异步架构**: 使用 `asyncio` 实现高效的并发任务调度
2. **优雅关闭**: 支持 Ctrl+C 优雅停止，清理资源
3. **错误处理**: 完善的异常捕获和日志记录
4. **可配置性**: 所有参数可通过配置文件调整
5. **模块化设计**: 各组件职责清晰，易于维护和扩展
6. **数据库集成**: 使用现有的 DatabaseManager 管理数据库连接
7. **重试机制**: 集成 TickFlowClient 的智能重试机制

## 注意事项

1. **API限流**: TickFlow API有频率限制，已通过批次大小和延迟进行控制
2. **数据库性能**: 大量数据同步可能影响数据库性能，建议在低峰期执行
3. **资源占用**: 实时行情任务每分钟执行，需确保服务器资源充足
4. **日志管理**: 定期清理日志文件，避免磁盘占满
5. **节假日**: 目前节假日判断功能待完善，暂时仅排除周末
