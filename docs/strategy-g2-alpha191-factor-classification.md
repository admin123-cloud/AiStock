## 使用建议

当前 Alpha191 在 G2 里分三层使用最清楚：

1. 候选池门控：只使用 T-1 已确认数据，避免把信号日收盘后状态用于盘中买点。优先沿用 `Alpha150 + Alpha095 + Alpha144`，再用 walk-forward 验证是否加入 `Alpha070` 或 `Alpha132`。
2. 环境确认：按因子族聚合，不逐个开关。量价族和量价相关族同时为正时，支持 NORMAL/AGGRESSIVE；波动拥挤恶化时，不升级仓位。
3. 风控降级：Alpha191 分数继续加严的边际收益有限。回撤保护更适合放在策略权益层，例如已测过的 `dd8_half`，而不是继续硬删候选。

## 已验证策略结论

已有研究显示：

- `Alpha150 + Alpha095 + Alpha144` 的 T-1 gate 已能形成可用过滤。
- `keep80/keep90` 不是越严越好，过度静态过滤会牺牲攻击性。
- `score_ge_050 + dd8_half_stop_cd3_skip` 更偏进攻，收益和 Sharpe 高，但回撤仍较高。
- `score050_overhead005 + dd8_half_stop_cd3_skip` 更偏稳健，适合继续做主力候选。

## 深化结合路线

作者报告的强结果不能直接照搬到 G2，但非常值得吸收。原因是作者做的是风格中性、多因子合成、T+2 调仓组合；G2 当前做的是已有候选池上的进攻型买点、盘中触发和交易管理。两者应做“分层结合”，而不是把 Alpha191 变成新的单一买入信号。

建议按四层推进：

1. 长样本复验层：先复现作者思路的统计口径，覆盖 `2010-2017`、`2018-2021`、`2022-2023`、`2024-2026` 四段，输出每个因子族的 IC、ICIR、top-bottom spread、单调性和稳定性。
2. G2 候选池解释层：只在 G2/V4 已经给出的候选池内计算 Alpha191 分层，回答“哪些候选更像作者体系里能产生交易型 Alpha 的票”。
3. T-1 门控层：因子只使用信号日前一交易日收盘后可确认的数据，避免把当日收盘信息塞进 10:00/10:30 买点。第一版保留 `Alpha150 + Alpha095 + Alpha144`，再比较加入 `Alpha070/Alpha132` 是否提高稳定性。
4. 风控仓位层：Alpha191 不直接决定清仓或重仓，而是影响 `PROBE/NORMAL/AGGRESSIVE` 的升级/降级，以及回撤保护触发后的半仓恢复速度。

优先实验矩阵：

| 实验 | 目标 | 关键判定 |
| --- | --- | --- |
| Author-style long IC | 验证 Alpha191 在长样本是否仍有横截面预测力 | 分段 ICIR、单调性、强因子留存率 |
| G2 pool overlay | 验证它能否在 G2 候选池内区分好坏 | 候选 top/bottom 分层收益、胜率、回撤 |
| T-1 gate walk-forward | 验证实盘可见条件下的过滤效果 | 训练期阈值、验证期和盲测期收益稳定性 |
| Factor-family state | 验证因子族能否帮助仓位状态机 | NORMAL/AGGRESSIVE 升级后的收益回撤比 |

第一版不建议做的事：

- 不把 191 个因子全部塞进一个黑箱评分。
- 不用全样本挑最优因子后直接上实盘。
- 不把信号日当日 OHLCV 或收盘后 Alpha191 值用于盘中买点。
- 不用作者 2012-2017 的结果替代我们 2018-2026 的复验。

最合理的落地目标是：让 Alpha191 成为 G2 的“质量筛选器”和“环境解释器”，保留 G2 现有进攻能力，再用长样本因子稳定性减少回撤和误触发。
