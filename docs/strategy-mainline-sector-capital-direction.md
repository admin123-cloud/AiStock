# 主线板块资金方向研究框架

## 背景

抖音视频《量化交易经典策略篇13如何找到主力强势板块吃肉喝汤》的核心观点可以抽象为一条 A 股特色资金路径：

`合适的市场环境 -> 资金集中进攻主线板块 -> 在主线板块内选择强个股 -> 持有强者恒强阶段`

这不是一个独立买点，而是一个上层方向过滤与排序增强层。它适合先作为 AiStock 的研究/影子验证模块，不应直接绕过现有 `g2_v2_complete`、市场门禁和实盘纪律。

## 核心假设

1. A 股资金结构变化后，市场更容易出现结构性分化，而不是普涨普跌。
2. 在机构、量化和大资金占比提升的阶段，资金会集中攻击少数方向。
3. 主线板块一旦形成，短期内通常会表现为强者恒强。
4. 个股选择应服从板块方向，优先在强板块中选强个股。
5. 板块强度需要用事前固定池验证，不能事后挑选已经上涨的板块。

## 与现有 AiStock 资产的关系

项目已经具备承接这个思路的基础：

- `sectors`：板块基础表。
- `sector_stocks`：板块成分映射，G2 数据血缘中已作为板块扩散真源。
- `sector_kline_daily`：板块日线与涨跌家数统计。
- `scripts/sync_sectors_and_mapping.py`：同步一/二/三级行业板块和成分映射。
- `scripts/generate_sector_kline.py`：按成分股生成板块日线统计。
- `scripts/gen2_research_volume5_sector_layer.py`：已验证 volume5 主线叠加板块扩散层。
- `scripts/gen2_research_breakout_sector_integration.py`：已验证突破主线叠加板块扩散层。
- `reports/g2_sector_integration_probe/sector_integration_report.md`：已有板块 gate 的回测结果。
- `reports/g2_volume5_sector_layer_probe/volume5_sector_layer_report.md`：已有 volume5 + 板块层验证结果。

因此下一步不是从零构造板块系统，而是新增一个更上层的“主线板块资金方向层”。

## 建议因子

建议新增研究因子名：

`mainline_sector_capital_strength`

它不是单一指标，而是一个分层评分：

| 层级 | 指标 | 含义 |
| --- | --- | --- |
| 市场环境 | 指数三层四态、成交额、赚钱效应 | 判断是否适合做主线追随 |
| 板块趋势 | 春节后/阶段累计涨幅、5/10/20 日相对强度 | 找主线方向 |
| 板块资金 | 成交额放大、换手扩张、量比 | 判断是否有资金持续进入 |
| 板块扩散 | 上涨家数占比、跑赢指数占比、创新高占比 | 判断是不是个别股独舞 |
| 个股强度 | 个股相对板块强度、volume5、突破/趋势状态 | 在主线内选强股 |

## 关键口径

### 1. 板块池必须事前固定

不能在回测中事后选择“光伏、电子、半导体”等已经表现好的方向。必须固定使用：

- 全部 `sector_stocks` 中的行业/细分行业板块；
- 或固定 ETF/指数池；
- 或固定申万/中信/同花顺一级、二级、三级行业口径。

若使用 ETF 池，也必须固定名单和起始日期，避免幸存者偏差。

### 2. 春节后强度只能作为一种锚点

视频强调“中国阴历年后”的资金重新布局，这个思路合理，但不能变成唯一锚点。建议同时验证：

- 农历春节后 5/10/20/40 个交易日累计强度；
- 每个自然月首个交易日后的阶段强度；
- 指数重新站回 MA20 后的阶段强度；
- 重大下跌修复后的阶段强度。

这样可以判断“春节效应”到底是有效锚点，还是只是一个年度叙事。

### 3. 主线板块不是买入信号

主线板块只能做三件事：

- 给候选股排序加分；
- 对弱板块候选降权或延迟确认；
- 在多个候选同时出现时优先选择主线方向。

正式买入仍必须满足：

- 市场门禁；
- `g2_v2_complete` 主线条件；
- 盘中可见确认；
- 板块扩散达标；
- 实盘页资金、仓位和止损纪律。

## 可验证版本

### V0：影子排名

只生成每日主线板块排行榜，不改变买卖逻辑。

输出字段：

- `trade_date`
- `sector_code`
- `sector_name`
- `level`
- `post_lunar_year_ret`
- `ret_5d`
- `ret_10d`
- `ret_20d`
- `excess_ret_20d`
- `amount_ratio_20d`
- `rise_ratio_5d`
- `strong_stock_ratio_5d`
- `limit_up_count_5d`
- `mainline_score`
- `mainline_rank`

### V1：候选股解释层

在实盘页和影子池展示：

- 候选股所属主线板块；
- 主线板块排名；
- 板块强度是否支持买入；
- 若不支持，标记“个股强但板块不跟随”。

仍不改变买点。

### V2：排序加分

在候选排序中加入轻量加分：

- 主线板块前 5：加分；
- 主线板块前 10：轻加分；
- 非主线但板块扩散达标：不加不减；
- 弱板块且扩散不足：降权。

先跑训练、验证、盲测，不直接上线。

### V3：组合层约束

只有在验证稳定后，才允许引入组合层约束：

- 同一主线板块最多持有 N 只；
- 弱市场环境下降低非主线仓位；
- 主线断裂时降低新增买入频率。

## 验证重点

必须检查：

- 是否使用未来函数；
- 板块成分是否为当时可见；
- 板块池是否事前固定；
- 春节后锚点是否过拟合；
- 强板块追高后的最大回撤；
- 板块强度失效后的退出延迟；
- 涨停、排队成交、滑点和手续费；
- 与 `g2_v2_complete` 原始收益的边际贡献；
- 是否只是 2026 年样本巧合。

## 初步工程路径

1. 先补一个 `scripts/gen2_research_mainline_sector_direction.py`，只生成主线板块日榜和候选股映射。
2. 输出到 `reports/mainline_sector_direction_probe/`。
3. 用现有 `g2_v2_complete` 信号作为候选池，叠加主线板块标签做归因。
4. 比较：
   - 原始 G2；
   - G2 + 主线排序；
   - G2 + 主线 gate；
   - G2 + 非主线降权；
   - G2 + 主线优先但不剔除。
5. 只有当盲测和分段窗口稳定提升后，再考虑进入页面展示或正式排序。

## 当前结论

这个视频思路值得吸收，但不应理解为“春节后哪个板块涨得多就买哪个”。更稳妥的落点是：

`用固定板块池识别资金主线，把它作为 G2 的方向过滤、排序解释和仓位权重参考。`

在 AiStock 当前体系里，它最适合先升级为“主线板块影子层”，服务于候选解释和排序，而不是直接变成新买点。
