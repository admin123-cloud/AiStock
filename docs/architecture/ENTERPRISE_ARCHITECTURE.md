# 企业级稳定架构设计与实现

## 项目概述

这是一个基于Python的AI量化交易系统，采用企业级稳定架构设计，旨在提供可靠、高效的A股股票数据获取和存储服务。

## 核心功能

### 1. 多数据源集成

- **通达信(pytdx)数据源**：实时行情主数据源，支持批量查询150只股票
- **东方财富数据源**：备用数据源，支持分钟级K线数据
- **Tushare数据源**：备用数据源，支持完整的历史数据
- **腾讯财经数据源**：应急数据源
- **新浪财经数据源**：应急数据源

### 2. 分钟级K线数据获取

支持以下周期的K线数据：
- 1分钟K线
- 5分钟K线
- 15分钟K线
- 30分钟K线
- 60分钟K线
- 日线、周线、月线

### 3. 数据源故障转移和负载均衡

- **智能故障转移**：当主数据源不可用时，自动切换到备用数据源
- **健康评分系统**：基于数据源的历史表现进行健康评分
- **动态负载均衡**：根据数据源的健康状态和响应速度分配请求
- **自动恢复机制**：数据源故障后自动尝试恢复

### 4. 数据存储优化

- **批量插入**：使用批量插入技术提高数据存储效率
- **索引优化**：为K线表和股票表添加合适的索引
- **数据清理**：定期清理过期的分钟级数据
- **数据压缩**：优化存储空间

### 5. 监控和告警机制

- **数据源健康检查**：定期检查所有数据源的健康状态
- **数据库健康检查**：监控数据库连接和性能
- **系统性能监控**：监控内存和CPU使用情况
- **告警通知**：支持邮件告警通知
- **告警历史**：记录所有告警事件

### 6. 任务调度系统

- **分钟级K线数据获取任务**：每15分钟执行一次
- **实时行情更新任务**：盘中每分钟执行一次
- **实时指数更新任务**：盘中每2分钟执行一次
- **全量K线同步任务**：每周六凌晨1点执行
- **盘中涨跌统计任务**：盘中每2分钟执行一次

### 7. 本地缓存机制

- **内存缓存**：快速访问频繁使用的数据
- **文件缓存**：持久化缓存重要数据
- **缓存过期策略**：自动清理过期缓存
- **缓存键管理**：统一的缓存键命名规范

### 核心模块

1. **data_sources/**：数据源管理和实现
   - `base.py`：数据源基类
   - `pytdx.py`：通达信数据源实现
   - `eastmoney.py`：东方财富数据源实现
   - `tushare.py`：Tushare数据源实现
   - `manager.py`：数据源管理器

2. **services/**：业务服务
   - `data_storage.py`：数据存储服务
   - `monitoring.py`：监控和告警服务
   - `cache.py`：本地缓存服务
   - `stock_service.py`：股票业务服务

3. **scheduler/**：任务调度系统
   - `scheduler.py`：任务调度器
   - `tasks/minute_kline_task.py`：分钟级K线数据获取任务

4. **models/**：数据模型
   - `stock.py`：股票相关数据模型

5. **utils/**：工具类
   - `database.py`：数据库连接管理
   - `logger.py`：日志管理
   - `config.py`：配置管理

## 配置说明

### 数据源配置

在 `backend/config/data_sources.yaml` 中配置数据源：

```yaml
# 通达信（实时行情主数据源）
pytdx:
  enabled: true
  priority: 1
  name: "通达信"
  description: "通达信行情服务器数据源"
  
  timeout: 10
  max_retries: 3
  retry_delay: 0.5
  batch_size: 150
  
  supported_types:
    - "stock_quote"
    - "realtime_quote"
  
  rate_limit:
    enabled: true
    requests_per_second: 5
    burst: 10
```

### 任务调度配置

在 `backend/src/scheduler/config.py` 中配置任务：

```python
# 每15分钟获取分钟级K线数据
"minute_kline": {
    "enabled": true,
    "description": "每15分钟获取股票的1、5、15、30、60分钟级K线数据",
    "trading_days_only": true,  # 只在交易日执行
    "trading_hours": {
        "start": "09:30",  # 上午开盘
        "end": "15:00",    # 下午收盘
    },
    "interval": 900,  # 900秒间隔（15分钟）
},
```

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置数据库

在 `.env` 文件中配置数据库连接：

```
# 数据库配置
DATABASE_URL=mysql+pymysql://root:password@localhost:3306/aistock
```

### 3. 初始化数据库

```bash
python backend/scripts/init_database.py
```

### 4. 启动服务

```bash
# 启动API服务
python backend/main.py

# 启动任务调度器
python backend/scheduler_run.py
```

### 5. 运行测试

```bash
python -m pytest backend/tests/test_enterprise_architecture.py -v
```

## 性能优化

### 1. 数据源优化

- **批量查询**：使用通达信数据源的批量查询功能，每次查询150只股票
- **速率限制**：为每个数据源设置合理的速率限制，避免被封禁
- **故障转移**：实现智能故障转移，提高系统可靠性

### 2. 存储优化

- **批量插入**：使用批量插入技术，减少数据库操作次数
- **索引优化**：为高频查询的字段添加索引
- **数据清理**：定期清理过期的分钟级数据，节省存储空间

### 3. 缓存优化

- **多级缓存**：使用内存缓存和文件缓存相结合的方式
- **缓存策略**：根据数据类型设置不同的缓存过期时间
- **缓存键管理**：使用统一的缓存键命名规范，便于管理

### 4. 监控优化

- **健康检查**：定期检查数据源和系统健康状态
- **告警机制**：及时发现和处理系统异常
- **性能监控**：监控系统资源使用情况，及时发现性能瓶颈

1. **多数据源备份**：至少3个数据源备份，确保数据获取的可靠性

本系统采用企业级稳定架构设计，通过多数据源集成、智能故障转移、数据存储优化、监控告警机制、任务调度系统和本地缓存机制，确保了系统的可靠性、高效性和可扩展性。
