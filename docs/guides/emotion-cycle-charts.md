# 情绪周期图表功能文档

## 功能概述

在首页新增了完整的情绪周期图表功能，支持多维度查看市场情绪变化趋势。

## 后端API

### 新增接口：`GET /api/market/emotion-trend`

获取情绪周期趋势数据。

**请求参数：**
- `days` (可选，默认30)：查询天数，支持 7/15/30/60/90

**返回数据：**
```json
{
  "dates": ["2026-03-01", "2026-03-02", ...],
  "close_up_rate": [45.5, 48.2, ...],      // 收盘上涨率
  "intraday_up_rate": [42.1, 44.8, ...],  // 盘中上涨率
  "strong_up_rate": [15.3, 18.6, ...],    // 强势上涨率
  "weak_up_rate": [30.2, 29.6, ...],      // 弱势上涨率
  "limit_up_follow_rate": [8.5, 10.2, ...],// 涨停溢价率
  "sh_up_rate": [44.2, 46.5, ...],        // 上证上涨率
  "sz_up_rate": [46.8, 49.1, ...],        // 深证上涨率
  "gem_up_rate": [42.5, 45.3, ...],       // 创业板上涨率
  "total": 30
}
```

## 前端功能

### 1. 数据范围选择
- 支持 7天/15天/30天/60天/90天 可选
- 切换范围后自动刷新数据

### 2. 图表交互
- **鼠标悬停**：显示详细数据提示框
- **滚轮缩放**：支持鼠标滚轮缩放查看
- **拖动平移**：支持鼠标拖动平移图表
- **图例点击**：点击图例可显示/隐藏对应数据线

### 3. 数据指标说明

| 指标 | 说明 | 颜色 |
|------|------|------|
| 收盘上涨率 | 收盘价高于开盘价的股票占比 | 红色（带填充） |
| 盘中上涨率 | 盘中曾上涨过的股票占比 | 橙色（虚线） |
| 强势上涨率 | 涨幅超过5%的股票占比 | 绿色 |
| 弱势上涨率 | 涨幅在0-5%的股票占比 | 灰色（点线） |
| 涨停溢价率 | 涨停股票的次日平均涨幅 | 蓝色（点划线） |

### 4. 图表样式优化
- 100% Y轴范围（0-100%）
- 渐变填充效果（仅收盘上涨率）
- 支持数据缩放滑块
- 优化的Tooltip提示框
- 响应式设计，自适应窗口大小

## 数据来源

情绪周期数据来自数据库表 `emotion_cycle`，包含以下字段：
- `date`: 交易日期
- `close_up_rate`: 收盘上涨率（%）
- `intraday_up_rate`: 盘中上涨率（%）
- `sh_up_rate`: 上证上涨率（%）
- `sz_up_rate`: 深证上涨率（%）
- `gem_up_rate`: 创业板上涨率（%）
- `strong_up_rate`: 强势上涨率（%）
- `limit_up_follow_rate`: 涨停溢价率（%）
- `weak_up_rate`: 弱势上涨率（%）

## 技术实现

### 前端
- 使用 ECharts 5.x 渲染图表
- Vue 3 Composition API 管理状态
- 支持窗口大小自适应
- 图表实例自动销毁重建

### 后端
- SQLAlchemy ORM 查询
- 支持参数化查询天数
- 异常处理和日志记录
- 返回空数据结构保持一致性

## 使用说明

### 正常访问
1. 确保后端服务已启动
2. 访问首页 http://localhost:5173/
3. 滚动到"情绪周期速率"区域
4. 查看趋势图表

### 无数据情况
如果数据库中没有情绪周期数据，图表区域会显示空状态，控制台输出错误日志。

### 数据生成
情绪周期数据需要通过定时任务或手动脚本生成，参考：
- `backend/src/scheduler/tasks/` 目录下的定时任务
- `backend/scripts/` 目录下的生成脚本

## 注意事项

1. **数据量限制**：最大支持90天数据，避免数据过多影响性能
2. **缓存机制**：前端无缓存，每次切换天数都会重新请求
3. **错误处理**：API错误会在前端控制台输出，图表区域不显示
4. **浏览器兼容**：支持现代浏览器（Chrome、Firefox、Edge、Safari）

## 测试方法

```bash
# 1. 启动后端服务
cd backend
python -m uvicorn src.main:app --reload

# 2. 测试API
curl "http://localhost:3000/api/market/emotion-trend?days=30"

# 3. 启动前端
cd frontend
npm run dev

# 4. 访问首页
# http://localhost:5173/
```
