# V5交易策略蓝图

## 目标

V5 的目标不是追求更复杂的分钟级确认，而是围绕以下三件事重构执行层：

1. 提高夏普
2. 压住组合回撤
3. 让尾盘选股、尾盘买入、次日卖出形成一套一致的实盘闭环

## 从 V4 / V4.2 总结出的经验

### 保留

1. 日线选股主框架有效
2. 组合模式 `on / neutral / off` 对控制持仓暴露有价值
3. 评分掉队、趋势破坏、止损止盈这些卖出理由仍然成立

### 弃用或降权

1. 不再把 `15m` 分钟确认当成买入收益的主要来源
2. 如果分钟级确认显著拉低夏普，不强行保留
3. 分钟线更多用于“否决明显错误交易”和“辅助减损”，而不是强制二次开仓确认

## V5 核心时序

### 1. 14:30 - 14:45 选股

使用当日 14:30 之前已经形成的数据，生成：

1. 当前策略持仓池
2. 买入候选
3. 卖出观察名单

这一步仍然以日线评分为主，不提前感知次日涨跌，也不依赖收盘后数据。

### 2. 14:50 买入决策

只有在以下条件同时满足时，才允许买入：

1. 当前模式不是 `off`
2. 冻结天数 `freeze_left = 0`
3. 组合当前持仓数未达到上限
4. 当日仍存在买入候选
5. 组合信号回撤未触发总仓位冻结

### 3. 尾盘分钟过滤

分钟级别在 V5 中只做“否决过滤”，不再默认做“强确认开仓”。

优先过滤以下情况：

1. 尾盘追高过热
2. 30 分钟趋势明显转弱
3. 15 分钟量能明显异常不足
4. 临近收盘流动性劣化

如果分钟过滤会显著降低夏普，则回退为：

1. 日线候选直接按尾盘执行
2. 分钟数据只参与风险提示，不拦截买入

## 卖出逻辑

V5 继续沿用 V4 已经验证过的卖出框架：

1. 单票止损
2. 单票止盈
3. 止盈后的 trailing
4. 趋势破坏卖出
5. 评分掉队卖出
6. 组合超出目标仓位时的弱股优先减仓

分钟线的职责：

1. 在盘中辅助确认止损 / 风险卖出
2. 在早盘出现明显失真时，优先做减损
3. 如果分钟信号不足，则回退日线既定卖出计划

## 组合风控

### 总仓位告警阈值

V5 明确把 `-8%` 设为组合级告警阈值，而不是单票阈值。

规则：

1. 当组合信号回撤 `<= -8%` 时，立即禁止新买入
2. 触发后冻结 `1` 个交易日
3. 冻结结束后恢复正常评估，不长期锁死

### 反死锁设计

冻结采用穿越触发（edge-triggered）：

1. 首次跌破 `-8%` 才触发冻结
2. 冻结期内不重复加锁
3. 解冻后若再次跌破，重新触发下一轮冻结

这样既保守，也避免长期停摆。

## 当前建议的 V5 执行原则

1. 选股主信号继续使用日线
2. 尾盘执行替代次日开盘追价
3. 分钟线默认只做否决过滤
4. 分钟线如果损害夏普，就进一步降权
5. 优先把分钟线价值放在卖出减损，而不是买入放大利润

## 实施顺序

### 第一阶段

1. 回测页显式显示真实策略版本
2. 区分 `v4 / v4.2_15m / v4.2_30m`
3. 避免把不同口径的夏普混在一起比较

### 第二阶段

1. 基于尾盘 14:30-14:50 流程，生成独立 V5 规则
2. 重新回测 `2026-01-01` 到当前区间
3. 对比：
   - V4 日线执行
   - V4.2 分钟确认执行
   - V5 尾盘执行

### 第三阶段

1. 若 V5 夏普更高，落地到“实盘交易 / 交易择时 / 交易选股”
2. 14:50 出现买点时触发邮件提醒
3. 保持回测与实盘共用一套规则口径
