# G2 第二代策略研究计划

## 定位

G2 是当前二代策略主线，目标是在页面、API、影子实盘和历史回测中统一使用 `g2_v2_complete`，不再把旧版 G2 单因子入口当成正式策略。

本计划用于约束后续研究、实现和上线验证，避免 API、gate、V4 参考池、盘中强度、板块扩散和风控逻辑之间出现口径漂移。

## 主线规则

- 主线一：`volume5_keep80_runup`，并在排序评分中加入板块扩散加分。
- 主线二：`big_bull_rebreak_2_5d + intraday_strength + l3_rt_strong3_ratio >= 0.05` 的突破买点。
- 盘中确认优先使用 15/30 分钟级别，必须保证信号在确认时刻真实可见。

## 数据要求

- 每日生成并校验 G2 V4 event dataset。
- 使用 D-1 已确认的 V4 参考池和 D-1 可见上下文，不把收盘后信息提前用于盘中买点。
- 盘中因子必须按确认 bar 截止重算，不能直接使用全天日线结果。
- 上游数据缺失、行数异常或文件不可读时，应中断本轮策略更新并告警。

## 研究纪律

- 严格区分研究候选、影子实盘和正式买点。
- 新买点未确认稳定收益前，不进入正式下单逻辑。
- 回测结论必须检查未来函数、滑点、涨跌停、费用、池子幸存者偏差和成交可执行性。
- 参数优化不得只看单次最优收益，应关注分段稳定性和失败样本。
- 页面、API、调度和报告必须使用同一套策略版本名与口径。
