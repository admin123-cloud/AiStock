# G2 Alpha191 策略收敛与归档说明（2026-05-26）

## 当前唯一主执行候选

`g2_alpha191_volume5_keep80_runup`

对应研究版本：`volume5_keep80_runup_le100`

核心规则：

- 基础池使用 G2 V3/User V2 risk_cool 候选。
- Alpha191 使用 T-1 已确认日线因子，避免盘中未来函数。
- `volume5 = Alpha150 + Alpha070 + Alpha095 + Alpha132 + Alpha144` 的训练分位数均值。
- keep80 弱过滤：保留训练期分位数不低于 20% 阈值的候选。
- 轻约束：`runup_from_60d_low <= 100%`。
- 组合引擎沿用 stop_cd3_skip、30m 风控、最多 2 仓、每日最多 1 笔、单票最多 50%。

## 移除策略与原因

| 策略族 | 处理 | 原因 |
| --- | --- | --- |
| `keep90/keep80/keep70` 旧三因子 gate | 移除 | 旧口径只用 Alpha150/095/144，收益和解释力均不如 volume5 主线。 |
| `score>=0.50` 系列 | 移除 | 高弹性但最大回撤偏大，`score_ge_050` 最大回撤 -19.62%，top5 毛利占比 40.82%，集中度偏重。 |
| `top50` 硬过滤 | 移除 | 多轮矩阵显示硬过滤明显牺牲收益，`Alpha144_top50` 甚至为负收益。 |
| `repair2` | 移除策略入口 | 候选池分层有用，但组合层收益不如 volume5/main3，只保留为环境修复研究素材。 |
| `tilt` 仓位倾斜 | 移除 | 降低回撤但也压低收益，不符合当前“先保留强进攻引擎，再优化回撤”的主线。 |
| `breadth<=80%` 单独约束 | 移除 | 会误删仍有价值的交易，全周期收益下降。 |

## 宝贵经验

1. Alpha191 不适合做无脑硬闸门。最有效的用法是“同日候选重排序 + 轻过滤”。
2. `volume5` 比旧三因子 gate 更适合组合层：量价/成交结构因子组合更能改善候选排序。
3. `runup<=100%` 是当前最有价值的轻约束：收益提升不是靠少数极端交易，而是共同交易排序/仓位质量改善。
4. `overhead<=5%` 是回撤控制工具，不是默认收益增强工具。它适合账户进入防守期时作为切换条件。
5. `top50` 这类硬切会破坏 G2 候选池的弹性，除非有更长盲测证明，否则不再作为主线。
6. score>=0.50 旧线提醒我们：高收益必须同时看回撤和利润集中度，不能只看全周期收益。
7. 后续新增 G2 策略必须先证明能超过 `g2_alpha191_volume5_keep80_runup` 的综合价值，否则只能作为研究归档，不进入第二代策略入口。
