# 历史实盘交易复盘与后续策略制定会话总结
整理时间：2026-05-07

## 1. 本次会话目标
1. 找到近1年真实交易中的主要问题。
2. 形成可执行的交易纪律与仓位方案。
3. 把 V4 强势池与实盘执行做成闭环。

## 2. 核心诊断
- 优势：能识别部分强势方向与主线。
- 问题不在“不会选股”，而在“执行偏情绪化”。
- 主要失分点：
  - 交易过散、出手过多。
  - 0-1天短持单亏损显著。
  - 亏损后补仓与反复做T。
  - 盘中冲动追单（直线拉升、冲板预期、图形幻想）。

## 3. 五条硬纪律
1. 持仓不超过3只。
2. 亏损单不补仓。
3. 新开仓至少按“可持有3天”预案进入。
4. 单票 -4% 禁加仓，-6% 必须处理。
5. 同一只股票同一周期最多买入2次（极少数强势票可3次）。

## 4. 执行风格结论
- 更适合“趋势确认 + 风险控制”，不适合高频情绪接力。
- 买点优先级：
  1) 缩量回踩低吸
  2) 平台突破确认追
  3) 情绪加速型少做或放弃
- 分钟线用途：否决错误买点与提示风险，不用于制造冲动买入理由。

## 5. 仓位建议（纪律修复期）
- 总资金：150,000
- 同时持有：最多2-3只（优先2只）
- 单票标准仓位：30,000
- 单票上限：37,500
- 组合标准总仓：60,000
- 组合绝对上限：75,000

## 6. V4 与实盘闭环
- 选股层：依赖 V4/V5 强势池，减少盘中随意扫票。
- 执行层：只做低风险确认，不做情绪冲动单。
- 复盘层：每天聚焦“是否违反纪律”，而非“今天感觉如何”。
