# G2 开仓与调仓位条件设计 v0.1

生成日期：2026-05-22

## 1. 设计原则

G2 的开仓判断不应该只依赖单一买点，也不应该把大量条件堆成一个难以解释的黑箱。当前版本先采用“少数主条件 + 状态化仓位”的方式：

- 指数趋势决定是否允许交易。
- 市场广度决定仓位强弱。
- 因子环境只做确认和风险过滤，不直接暴力拟合最优组合。
- 输出不是简单二元开关，而是 `OFF / PROBE / NORMAL / AGGRESSIVE` 四种状态。
- 条件数量尽量少，参数尽量稳定，后续所有回测都必须先固定规则再验证。

## 2. 核心结论

建议把 G2 的第一版开仓门控定为：

```text
主开仓代理：中证1000 close > MA20
风险确认：上证指数不处于明显弱势
仓位调节：全市场 MA20 广度
环境确认：191 因子族的市场级风险偏好
```

这里不用单纯看上证指数，是因为 G2 未来主要交易 V4 参考池中的活跃个股，中证1000和中证500更贴近这类标的的风险偏好。上证指数更适合作为系统风险确认，而不是唯一开仓开关。

## 3. 简洁状态机

### 3.1 OFF：不新开仓

满足任一条件即进入 OFF：

```text
中证1000 close <= MA20
AND 全市场 close > MA20 比例 < 40%
```

或：

```text
中证1000 close <= MA20
AND 上证指数 close <= MA20
```

含义：活跃股代理指数和大盘风险确认同时偏弱时，不做新开仓。已有仓位按卖出规则管理，不因开仓门关闭而机械立即清仓。

### 3.2 PROBE：试探开仓

满足以下任一组条件：

```text
中证1000 close > MA20
AND 全市场 close > MA20 比例在 30% - 45%
```

或：

```text
中证1000 close > MA20
AND MA20_slope_5d <= 0
```

或：

```text
中证1000 close <= MA20
AND 中证500 close > MA20
AND 全市场广度连续 3 日改善
```

建议仓位：`0% - 30%`。只允许最强信号、最高质量标的，控制每日新开仓数量。

### 3.3 NORMAL：正常开仓

建议作为 G2 默认有效交易状态：

```text
中证1000 close > MA20
AND (中证1000 MA20_slope_5d > 0 OR 中证500 close > MA20)
AND 全市场 close > MA20 比例 >= 45%
AND 上证指数不触发系统风险确认
```

其中“上证指数不触发系统风险确认”先定义为：

```text
上证指数 close > MA20
OR 上证指数 MA20_slope_5d > 0
OR 全市场广度 >= 55%
```

建议仓位：`30% - 70%`。这是后续 V4/G2 买点验证的主交易区间。

### 3.4 AGGRESSIVE：积极开仓

只有市场环境明显顺风时才进入：

```text
中证1000 close > MA20
AND 中证500 close > MA20
AND 至少一个成长/风险偏好指数 close > MA20
AND 全市场 close > MA20 比例 >= 60%
AND 191 因子族风险偏好确认通过
```

成长/风险偏好指数可先用创业板指，后续也可加入科创相关指数，但不要一开始扩大过多。

建议仓位：`70% - 90%`。只在因子环境和市场广度都支持时使用，不作为常态。

## 4. 191 因子的使用方式

国泰君安 191 因子不建议在开仓门控中逐个试参数。第一阶段只把它们聚合成少数“因子族环境指标”。

### 4.1 动量/趋势因子族

用途：确认市场是否奖励强势股。

候选指标：

- 动量类因子 Top 20% 组合未来收益是否持续强于 Bottom 20%。
- 最近 20 日 RankIC 均值是否为正。
- V4 参考池内高动量股票占比是否上升。

开仓用途：

```text
动量因子族为正 -> 允许 NORMAL 升级到 AGGRESSIVE
动量因子族转负 -> AGGRESSIVE 降级到 NORMAL/PROBE
```

### 4.2 量价/流动性因子族

用途：判断风险偏好是否扩散，而不是只集中在少数票。

候选指标：

- 成交额改善股票占比。
- 换手率温和抬升股票占比。
- 放量上涨股票数量相对放量下跌股票数量的比例。

开仓用途：

```text
流动性扩散 -> 支持 NORMAL
流动性收缩且指数贴近 MA20 -> 降级 PROBE
```

### 4.3 波动/拥挤因子族

用途：避免高位追涨和系统性回撤。

候选指标：

- 高波动股票占比是否过高。
- 短期涨幅过大且换手剧烈的股票占比是否异常。
- 指数下跌同时波动率扩张，视为风险恶化。

开仓用途：

```text
波动扩张且收益为负 -> 禁止 AGGRESSIVE
极端拥挤 -> 新开仓降级
```

### 4.4 反转/修复因子族

用途：识别弱势修复行情，避免把反弹误判成主升。

候选指标：

- 短期超跌反弹因子的有效性。
- 低位修复股票占比。
- 冰点修复后 2-3 日的收益扩散情况。

开仓用途：

```text
反转修复有效但趋势未确认 -> 只允许 PROBE
趋势确认后再升级 NORMAL
```

## 5. 推荐落地版规则

为了保持简洁，第一版不要同时启用太多因子族。建议先落地以下版本：

```text
G2_OPEN_STATE =
  OFF        if 活跃指数弱 AND 广度弱
  PROBE      if 活跃指数刚转强但广度不足
  NORMAL     if 活跃指数站上 MA20 且广度 >= 45%
  AGGRESSIVE if NORMAL 且广度 >= 60% 且动量/流动性因子族确认
```

实际判断字段：

```text
active_index = 中证1000
risk_index = 上证指数
confirm_index = 中证500
growth_index = 创业板指
breadth = 全市场 close > MA20 比例
factor_risk_on = 动量因子族为正 AND 流动性因子族为正 AND 波动拥挤不过热
```

仓位映射：

| 状态 | 新开仓 | 目标总仓位 | 说明 |
| --- | ---: | ---: | --- |
| OFF | 0 | 0% - 20% | 不开新仓，只管理旧仓 |
| PROBE | 允许少量 | 0% - 30% | 只做最高质量信号 |
| NORMAL | 允许 | 30% - 70% | G2 主交易区间 |
| AGGRESSIVE | 允许 | 70% - 90% | 只在顺风环境启用 |

## 6. 不建议采用的规则

以下规则暂不建议进入 G2：

- 单日上穿 MA20 就满仓。
- 只看上证指数决定全部交易。
- 把 191 个因子逐个参数搜索后选收益最高组合。
- 同时使用 8 个以上开仓条件。
- 用过窄窗口的一次回测收益决定正式规则。
- 把市场广度作为唯一开关。广度更适合作为仓位调节器。

## 7. 下一步研究顺序

阶段 B 后续建议先做“市场状态表”，暂不急着验证组合收益：

1. 生成 2010 至今每日 `G2_OPEN_STATE`。
2. 把每一天的指数条件、广度条件、因子族条件拆开记录。
3. 先统计不同状态下指数未来 1/3/5/10/20 日收益。
4. 再统计 V4 参考池在不同状态下的未来收益。
5. 最后才接入真实买点和组合收益。

这样可以先判断“什么时候应该交易”，再判断“交易什么”和“如何持有”，避免把择时、选股、卖出混成一团。

## 8. 收益比较口径

后续评估不同开仓状态或不同简洁组合条件时，不能只看组合绝对收益。建议固定三层比较：

1. 指数自身收益：比较上证、中证500、中证1000、创业板指在不同状态下未来 1/3/5/10/20 日涨幅。
2. V4 参考池收益：比较 `entry_top10`、`entry_top30`、`entry_all`、`score_pool` 在不同状态下的未来收益。
3. 相对指数超额：V4 参考池收益减去中证1000同期收益，判断收益来自选股还是只是跟随指数上涨。

优先观察：

- `AGGRESSIVE` 是否同时提升指数收益和 V4 参考池收益。
- `OFF` 是否显著压低负收益、回撤或低胜率交易。
- `PROBE` 是否只是弱修复阶段，适合小仓位而非正常开仓。
- V4 参考池是否在同一状态下持续跑赢中证1000。

只有当开仓状态同时对指数环境和 V4 参考池有解释力时，才值得进入组合回测。
